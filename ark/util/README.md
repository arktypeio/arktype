# @ark/util

Internal. The utilities [ArkType](https://arktype.io) and its packages are written with: type-level helpers, functions over objects, arrays, strings and numbers, and the errors they throw.

It isn't published: `arktype` bundles it and exposes it as `arktype/util`, and workspace packages import it directly. `arktype/util` isn't semver-stable: an export can change or go in any release.
