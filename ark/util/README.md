# @ark/util

The utilities [ArkType](https://arktype.io) and its packages are written with: type-level helpers, functions over objects, arrays, strings and numbers, and the errors they throw.

It's published because `arktype`, `@ark/schema`, `arksets`, `arkregex` and `@ark/attest` depend on it, not as a library of its own. It isn't semver-stable: an export can change or go in any release. Install [`arktype`](https://www.npmjs.com/package/arktype) instead, and if your code needs something from here, pin an exact version.
