# @ark/fs

File system, shell and call-site helpers for Node, written for [`@ark/attest`](https://www.npmjs.com/package/@ark/attest) and the scripts of the [ArkType](https://arktype.io) repo.

It's published because `@ark/attest` depends on it, not as a library of its own. It isn't semver-stable: an export can change or go in any release, so pin an exact version if your code imports it.
