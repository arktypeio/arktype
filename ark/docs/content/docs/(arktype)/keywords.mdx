## TypeScript [#typescript]

TypeScript's built-in types are keywords, except `any` and `void`, which don't mean anything useful at runtime. If you need `any`, use `unknown.any`.

<SyntaxTabs>
	<SyntaxTab string>

```ts
const Keywords = type({
	string: "string",
	date: "Date"
})
```

    </SyntaxTab>

    <SyntaxTab fluent>

```ts
const Keywords = type({
	string: type.string,
	date: type.Date
})
```

    </SyntaxTab>

</SyntaxTabs>

These keywords are attached directly to `type`: `string`, `number`, `bigint`, `boolean`, `symbol`, `undefined`, `null`, `object`, `unknown`, `true`, `false`, `never`, `Key`, `Array`, `Date`, `Record` and `arrayIndex`. Every keyword is available in `type.keywords`.

## Subtypes [#subtype]

A subtype keyword refines or transforms its parent, like `string.email` or `string.date.parse`. To find them in your editor, start a definition like `"string."` and let autocomplete list them.

<SyntaxTabs>
	<SyntaxTab string>

```ts
const Keywords = type({
	dateString: "string.date",
	isoDateString: "string.date.iso",
	parsedDate: "string.date.parse",
	parsedIsoDate: "string.date.iso.parse"
})
```

    </SyntaxTab>

    <SyntaxTab fluent>

```ts
const Keywords = type({
	dateString: type.keywords.string.date.root,
	isoDateString: type.keywords.string.date.iso.root,
	parsedDate: type.keywords.string.date.parse,
	parsedIsoDate: type.keywords.string.date.iso.parse
})
```

A keyword with subtypes, like `string.date`, is a module. Its `.root` is the keyword's own `Type`.

    </SyntaxTab>

</SyntaxTabs>
