title: Adding constraints
description: Narrow types beyond what TypeScript can express, with keywords, ranges, divisors and custom predicates.
---

TypeScript can represent types like `string` or `number`, but what about `email` or `integer less than 100`?

In ArkType, conditions that narrow a type beyond its **basis** are called **constraints**. They compose with TypeScript's operators like any other part of a definition.

## Define

Let's create a new `Contact` Type that enforces our example constraints.

```ts
const Contact = type({
	// many common constraints are available as built-in keywords
	email: "string.email",
	// others can be written as type-safe expressions
	score: "number.integer < 100"
})

// infer the TypeScript type as usual
type Contact = typeof Contact.infer
```

<Callout type="info" title="number excludes NaN and Infinity">
	`number` rejects `NaN`, `Infinity` and `-Infinity` by default. To allow them,
	see `number.NaN`, `number.Infinity` and `number.NegativeInfinity` in
	[Keywords](/docs/keywords), or the `numberAllowsNaN` and
	`numberAllowsInfinity` options in [Configuration](/docs/configuration).
</Callout>

## Compose

Imagine we want to define a new Type representing a non-empty list of `Contact`.

Definitions create new types. Chained methods refine or transform types you already have.

```ts
const Contact = type({
	email: "string.email",
	score: "number.integer < 100"
})
// ---cut---
// a non-empty list of Contact
const Contacts = Contact.array().atLeastLength(1)

// ArkErrors: must be non-empty
const out = Contacts([])
```

## Narrow

Structured constraints like divisors and ranges will only take us so far. For anything else, add your own logic with `.narrow`.

```ts
// there's no "not divisible" expression - need to narrow
const Odd = type("number").narrow((n, ctx) =>
	// if even, add a customizable error and return false
	n % 2 === 0 ? ctx.mustBe("odd") : true
)

const FavoriteNumbers = type({
	even: "number % 2",
	odd: Odd
})

const out = FavoriteNumbers({
	even: 7,
	odd: 8
})

if (out instanceof type.errors) {
	// ArkErrors: even must be even (was 7)
	//            odd must be odd (was 8)
	console.error(out.summary)
} else {
	console.log(out.odd)
}
```

You now know how to refine your types to enforce additional constraints at runtime.
