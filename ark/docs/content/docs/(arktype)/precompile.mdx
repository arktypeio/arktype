---
title: Precompile
---

`@ark/precompile` constructs your Types when you build, so arktype's parser never ships and nothing compiles at runtime. Your definitions stay as you wrote them.

```sh
npm i -D @ark/precompile
```

Add its plugin to your bundler. It works with Vite, Rollup, Rolldown, webpack, Rspack, esbuild, Bun and Farm, and Vitest runs tests through it too:

```ts title="vite.config.ts"
import { precompile } from "@ark/precompile/unplugin"

export default {
	plugins: [precompile.vite()]
}
```

### Standalone validators

By default, each definition becomes a standalone validator running on `arktype/runtime`. It validates, asserts and implements Standard Schema as the Type it replaces does, so it validates under a Content-Security-Policy that blocks `eval`. It differs from a Type in a few ways:

- It lacks the methods that compose a Type, like `.and` or `.in`, so the build fails where it sees one read outside a definition it precompiles.
- Its errors say what failed but not what the value was, like `name must be a string`.
- A definition the build can't construct, like one reading a value known only at runtime, fails the build with the reason. List them before you switch:

```sh
npx arktype-precompile --check "src/**/*.ts"
```

`runtime: "arktype"` ships arktype instead: definitions stay Types, and the build registers the code arktype would compile for each, so a Type it could precompile skips compiling at runtime.

### Options

A standalone build can leave out what your program doesn't need:

```ts
import { precompile } from "@ark/precompile/unplugin"
// ---cut---
precompile.vite({
	errors: "none",
	mutatesInput: "always",
	members: { assert: false }
})
```

- `errors` and `mutatesInput` take the values of [`errors`](/docs/configuration#errors) and [`mutatesInput`](/docs/configuration#mutatesinput). A program that also configures one must configure the same value.
- `members` decides what a validator has besides validating, like `assert`, `~standard` or `toJsonSchema()`.
- `optimize: "size"` writes validators for size rather than speed.

A program that calls `configure()` does so once, in a module imported before any that defines a Type, and names it as the build's `config`:

```ts
import { precompile } from "@ark/precompile/unplugin"
// ---cut---
precompile.vite({ config: "./config.ts" })
```

The [`@ark/precompile` README](https://github.com/arktypeio/arktype/tree/main/ark/precompile#readme) is the full reference: every option, the Node, Bun and Turbopack drivers, shadow mode for tests, libraries, runtime islands and declarations.
