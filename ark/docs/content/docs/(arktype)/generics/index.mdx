A generic is a definition with parameters. Instantiating it with a definition for each parameter returns a `Type`.

## Keywords

Like TypeScript's utility types, these generics are available in any definition:

<GenericKeywordTable />

Instantiate one in a string, or call it from `type.keywords`:

```ts
const One = type("Extract<0 | 1, 1>")

const Unfalse = type.keywords.Exclude("boolean", "false")
```

`Record` is also available as `type.Record`. Generics like `Pick` and `Partial` have [method equivalents](/docs/objects#properties-pick-omit) on object Types, such as `User.pick("name")`.

## Syntax

### Definition

Pass a string of parameter names in angle brackets, then a definition that references them:

```ts
const BoxOf = type("<t>", { box: "t" })

// Type<{ box: string }>
const StringBox = BoxOf("string")
```

`type.generic("t")({ box: "t" })` is equivalent.

### Constraints

Constrain a parameter with `extends`. Arguments must satisfy the constraint, and the definition can use the parameter wherever its constraint is allowed, like with the `>` operator here:

```ts
// @errors: 2345
const NonEmpty = type("<arr extends unknown[]>", "arr > 0")

// Type<number[]>
const NonEmptyNumbers = NonEmpty("number[]")

// ParseError: arr must be assignable to Array (was string)
NonEmpty("string")
```

With `type.generic`, pass a `[name, constraint]` tuple: `type.generic(["arr", "unknown[]"])("arr > 0")`.

### Scoped

In a [scope](/docs/scopes), declare parameters in the alias name:

```ts
const types = scope({
	"Box<t, u>": { box: "t | u" },
	BitBox: "Box<0, 1>"
}).export()

// ArkErrors: box must be 0 or 1 (was 2)
types.BitBox({ box: 2 })
```

### Recursive

A scoped generic can reference itself:

```ts
const types = scope({
	"Tree<t>": { value: "t", "children?": "Tree<t>[]" },
	NumberTree: "Tree<number>"
}).export()

// ArkErrors: children[0].value must be a number (was a string)
types.NumberTree({ value: 1, children: [{ value: "2" }] })
```

## HKT

`generic()` with an `Hkt` class wraps a type-level TypeScript function as an ArkType generic. The function transforms the arguments at runtime, and the class's `body` describes the result at the type level. This is how `Partial` is implemented:

```ts
import { generic, Hkt } from "arktype"

const Partial = generic(["T", "object"])(
	args => args.T.partial(),
	class PartialHkt extends Hkt<[object]> {
		declare body: Partial<this[0]>
	}
)

// Type<{ a?: string }>
const PartialA = Partial({ a: "string" })
```

For more examples, see the [generic tests](https://github.com/arktypeio/arktype/blob/HEAD/ark/type/__tests__/generic.test.ts).

## External

To write a TypeScript function that accepts and returns Types, constrain a parameter with `type.Any`:

```ts
const createBox = <t extends string>(of: type.Any<t>) =>
	type({
		box: of
	})

// @ts-expect-error
createBox(type("number"))

// Type<{ box: string }>
const BoxType = createBox(type("string"))
```

To accept a definition instead, validate it with `type.validate` and infer the result with `type.instantiate`:

```ts
const createBox = <const def>(
	of: type.validate<def>
): type.instantiate<{ box: def }> =>
	type.raw({
		box: of
	}) as never

// Type<{ box: string }>
const BoxType = createBox("string")
```

TypeScript generics like these can be hard to get right. If yours isn't inferring as expected, see [the FAQ](/docs/faq#why-isnt-my-wrapper-generic-working).
