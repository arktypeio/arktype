---
title: Traversal API
description: The ctx argument that narrow and pipe functions receive for reading the current path and reporting errors.
---

Functions you pass to [`.narrow`](/docs/expressions#narrow) and [`.pipe`](/docs/expressions#pipe) receive a `ctx` as their second argument. Use it to report errors that read like ArkType's own:

```ts
const Even = type("number").narrow(
	(n, ctx) => n % 2 === 0 || ctx.mustBe("even")
)

// ArkErrors: must be even
Even(3)
```

A narrow returns `ctx.mustBe(...)` or `ctx.reject(...)`, which add an error and return `false`. A morph returns `ctx.error(...)`, which adds an error and returns it:

```ts
const Json = type("string").pipe((s, ctx) => {
	try {
		return JSON.parse(s)
	} catch {
		return ctx.error("valid JSON")
	}
})

// ArkErrors: must be valid JSON
Json("{")
```

`reject` and `error` take a string, which is what the value must be, or the [parts of an error](/docs/configuration#error-messages): `expected` and `actual`, or a `message` that replaces the whole sentence. `relativePath` reports it below the value being checked, where `path` would replace its whole path from the root of the data:

```ts
const Range = type({ start: "number", end: "number" }).narrow(
	(range, ctx) =>
		range.start <= range.end ||
		ctx.reject({
			expected: "at least start",
			actual: `${range.end}`,
			relativePath: ["end"]
		})
)

// ArkErrors: end must be at least start (was 1)
Range({ start: 2, end: 1 })

const Booking = type({ stay: Range }).narrow(
	(booking, ctx) =>
		booking.stay.end - booking.stay.start <= 30 ||
		ctx.reject({ message: "Book 30 nights or fewer", relativePath: ["stay"] })
)

// ArkErrors: stay: Book 30 nights or fewer
Booking({ stay: { start: 1, end: 60 } })
```

To write a check outside the call, type `ctx` with `Traversal`:

```ts
import { type, type Traversal } from "arktype"

const isEven = (n: number, ctx: Traversal) => n % 2 === 0 || ctx.mustBe("even")

const Even = type("number").narrow(isEven)
```
