# Scopes

<Callout type="info">
	A scope resolves names like `"user"` across its definitions.
</Callout>

```ts
const $ = scope({
	user: { name: "string", friends: "user[]" },
	group: { members: "user[]", "owner?": "user" }
})

const types = $.export()
const out = types.group({ members: [] })
```

Inline JSX works too: <code>{type("string | number").expression}</code>.

{/* a comment in MDX */}
